O objetivo deste documento é apresentar todas as especificações dos requisitos
funcionais do caso de uso \ucnome.

\section{Breve Descrição}

A função deste caso de uso é permitir que o usuário do sistema, coordenador ou
professor, seja capaz de visualizar, criar, editar e excluir agendamentos, com
suas devidas permissões no sistema.

\section{Fluxo Básico de Eventos}

\begin{fluxo}
  \item O usuário acessa o menu principal.
  \item O usuário acessa a seção de gerenciamento de agendamentos.
  \item O usuário escolhe a opção de criar agendamentos.
  \item O sistema exibe um formulário de cadastro de agendamentos.
  \item O usuário faz a inserção dos dados.
  \item O usuário salva o cadastro do novo agendamento.
  \item O sistema valida e salva os dados recebidos e finaliza o processo de
        cadastro.
\end{fluxo}

\section{Fluxos Alternativos}

Nesta seção, serão abordados fluxos alternativos relacionados ao caso de uso
\ucnome. Um fluxo alternativo representa um comportamento alternativo,
geralmente derivado de exceções que ocorrem no fluxo principal.

\subsection{Visualizar Agendamentos}

\begin{fluxo}
  \item O usuário acessa o menu principal.
  \item O usuário acessa a seção de gerenciamento de agendamentos.
  \item O usuário seleciona um agendamento.
  \item O usuário visualiza as informações desejadas.
\end{fluxo}

\subsection{Editar Agendamentos}

\begin{fluxo}
  \item O usuário acessa o menu principal.
  \item O usuário acessa a seção de gerenciamento de agendamentos.
  \item O usuário seleciona o agendamento que deseja editar.
  \item O usuário faz a alteração dos dados.
  \item O sistema valida e salva os dados recebidos e finaliza o processo.
\end{fluxo}

\subsection{Excluir Agendamentos}

\begin{fluxo}
  \item O usuário acessa o menu principal.
  \item O usuário acessa a seção de gerenciamento de agendamentos.
  \item O usuário seleciona o agendamento que deseja excluir.
  \item O usuário seleciona a opção de excluir.
  \item Os dados são excluídos do sistema.
\end{fluxo}

\subsection{Tratamento de Dados}

O sistema valida os dados inseridos pelo usuário. O sistema apresenta uma
mensagem de erro caso os dados inseridos pelo usuário não estejam adequados
para o sistema.

\section{Subfluxos}

Não existem subfluxos associados a este caso de uso.

\section{Cenários Chave}

Os cenários-chave deste caso de uso são: criação, visualização, edição e
exclusão de agendamentos cadastrados no sistema.

\section{Condições Prévias}

Não se aplica.

\section{Condições Posteriores}

Nesta seção serão listados os possíveis estados do sistema imediatamente após
a conclusão do caso de uso em questão.

\subsection{Cadastrar Agendamento}

Um agendamento será cadastrado no sistema e salvo no banco de dados.

\subsection{Editar Agendamento}

Um agendamento existente terá suas informações atualizadas com novas
informações no banco de dados.

\subsection{Deletar Agendamento}

Um agendamento existente será apagado do banco de dados.

\section{Pontos de Extensão}

O caso de uso \ucnome{} não possui pontos de extensão.

\section{Requisitos Especiais}

O caso de uso \ucnome{} não possui requisitos especiais.
