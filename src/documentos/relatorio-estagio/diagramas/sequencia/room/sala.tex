\subsubsection{Sala}

Nas figuras a seguir são apresentados os diagramas de sequência das operações sobre a entidade \texttt{Room}.

\begin{itemize}
    \item A Figura~\ref{fig:seq-create-room} representa o fluxo de criação de uma nova sala, incluindo a associação opcional de recursos.
    \item A Figura~\ref{fig:seq-get-room-simple} representa as operações de consulta: listagem de todas as salas e busca por identificador.
    \item A Figura~\ref{fig:seq-update-room} representa a atualização dos dados de uma sala existente.
    \item A Figura~\ref{fig:seq-update-room-status} representa a alteração do status de uma sala, respeitando as transições de estado válidas.
    \item A Figura~\ref{fig:seq-replace-room-resources} representa a substituição completa do conjunto de recursos associados a uma sala.
    \item A Figura~\ref{fig:seq-delete-room} representa a exclusão lógica (\textit{soft delete}) de uma sala, que exige status \texttt{ARCHIVED} e marca o registro com status \texttt{DELETED}.
\end{itemize}
